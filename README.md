# Un-Corporate 

#### An AI-powered web utility that translates dense, confusing corporate legalese, employment contracts, and sketchy terms of service into direct, plain, and brutally honest English for teenagers.

**Powered by Node.js, Express, and the OpenAI API (gpt-4o-mini).**

---

## ✨ Features
* **Split-Screen UI:** Clean, distraction-free environment built with Tailwind CSS.

* **Tone Control:** Toggle between different translation styles:

   * 🥱 Plain English: Straightforward, simplified facts.

   * 💀 Brutally Honest: No corporate sugarcoating.

   * 🛹 Gen-Z Slang: Direct internet-culture translation.

* **Privacy Minded:** Built using secure server-side environment handling to protect sensitive API endpoints.

--- 

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation
Clone the repository:

```Bash
git clone https://github.com/jeswintom22/Un-Corporate.git
cd Un-Corporate
```
Install dependencies:

```Bash
npm install
```
### Running the App

Set up your OpenAI API Key in your terminal environment:

#### Mac/Linux:

```Bash
export OPENAI_API_KEY="your-actual-api-key"
```
#### Windows (PowerShell):

```PowerShell
$env:OPENAI_API_KEY="your-actual-api-key"
```
### Start the backend Node server:

```Bash
node server.js
```
### Open the application:
Simply double-click the index.html file in your project folder to open it locally in any web browser.
